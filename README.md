# RepairFAQ photo galleries

Photos from three galleries of [repairfaq.org](https://www.repairfaq.org/): the Laser Equipment Gallery
(`sam/laserpic`), the repair photo dissections (`sam/reppic`) and the brochures (`sam/brochures`). They are kept at
the same paths under `archive/`.

They are served here for the mirror at https://acamarocutcher.github.io/repairfaq/
([repository](https://github.com/AcamaroCutcher/repairfaq)), whose pages display them. They live in their own
repository because GitHub Pages limits each site to 1 GB.

non-commercial use only. This repository is generated by `tools/build.py` in the `repairfaq` repository. Do not edit
it by hand.
